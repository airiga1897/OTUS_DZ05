# Согласованный состав и стоимость

Создание согласовано пользователем 19.10.2026 для приведённого состава и стоимости.

| Роль | Число | vCPU/ГиБ на узел | SSD на узел |
|---|---:|---:|---:|
| MySQL InnoDB Cluster | 3 | 2/4 | 20 ГБ |
| Nginx, Django, uWSGI, MySQL Router | 1 | 1/2 | 20 ГБ |

Итого 7 vCPU, 14 ГиБ RAM, 80 ГБ basicssd, один floating IPv4,
одна приватная сеть /24, один обычный роутер, четыре порта ВМ и одна
группа anti-affinity БД. Без Octavia, Kubernetes, GFS2 и ресурсов ДЗ06.
Весь стенд в ru-9a: проверяется отказ ВМ, не отказ ЦОД.

Расчёт по актуальному публичному прайсу Selectel от 18.10.2026: 13.82 ₽/час,
331.59 ₽/сутки, 9947.79 ₽ за 30 суток. Расчёт предполагает, что значения
сохранённого прайса заданы в копейках за час:

`(7*100.71072 + 14336*0.03576375 + 80*1.382340862 + 25.968384 + 27.39726027)/100`

Источник: https://api.selectel.ru/prices/vpc?currency=rub — API прайса,
который использует официальный калькулятор https://selectel.ru/services/cloud/servers/.
Ставки и расчёт сохранены в cost-live.json. Это публичные ставки, без учёта
индивидуальных скидок. Резервные копии и платный исходящий трафик не включены.
Остановка ВМ не отменяет оплату дисков и IP.

Удаление выполняется отдельной командой после проверки. Остановка ВМ не удаляет диски и IP.

Сохранённая проверка квот при испытании (не текущая гарантия свободной ёмкости): в ru-9a свободны 600 vCPU,
5120000 MiB RAM, 1000 ВМ; в ru-9 свободны 12 floating IP, 100 сетей,
100 подсетей, 20 роутеров. Compute/Neutron учитывают текущее общее потребление
проекта; при проверке оно было нулевым, кроме стандартной security group.
Cinder с оператором подтвердил 600 ГБ basicssd.ru-9a: занято 0, зарезервировано 0.
На оба стенда требуется 160 ГБ, свободного SSD достаточно. Перед apply повторить все проверки, учитывая ДЗ06.
