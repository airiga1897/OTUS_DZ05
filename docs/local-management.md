# Локальная проверка управления

Проверяется интерфейс управления текущего кода без создания, изменения или
удаления облачных ресурсов. Используются синтетические значения, временные
каталоги и mock API. Эти результаты не заменяют проверку реального стенда.

```powershell
.\.tools\venv\Scripts\python.exe -m unittest discover -s tests -p 'test_*.py'
powershell -NoProfile -File .\tests\test_credentials.ps1
```

| Проверка | Подтверждено локально |
| --- | --- |
| Python | 42 теста проходят |
| Credentials PowerShell | Ввод без файла, сохранение, загрузка, -Dev, взаимоисключение ключей |
| Доступ к файлу | Общий доступ отклоняется до чтения |
| Источник Python/Terraform | Окружение, без файлового fallback |
| open | Корректный контекст открывается, отсутствующий и устаревший отклоняются |
| Изоляция | Несовпадение проекта, региона и имён ресурсов отклоняется |
| Очистка | Непустой state блокирует удаление; при успехе сохраняются конфигурация и credentials |
| Ошибки удаления | Локальные данные сохраняются при ошибке облачного аудита |
| Перебор пулов | Каталоги, квоты, очистка перед повтором, блокировка перехода при ошибке аудита |
| Временные данные | Изолированные каталоги удаляются средствами TemporaryDirectory/finally |

Ручной прогон базового стенда с пятью статьями подтверждён
[отчётом](verification-20261020T201205Z.json) и [удалением](cleanup-latest.json).
Одиннадцать текущих Django-тестов проходят локально на SQLite в памяти.

Следующий облачный прогон выполняется только по отдельному согласованию.

Контракты расширения и временного цикла проверены только mock-тестами;
[облачная приёмка добавления узла](expansion.md) остаётся открытой.

Ansible-роли встроены в deploy. Локально проверены их исходники и mock-запуск;
Linux-контроллер на app и реальное применение требуют согласованного испытания.
Проверены откат загрузки фикстуры вместе с DB-маркером и принятие существующих
данных без перезаписи при отсутствии маркера.
