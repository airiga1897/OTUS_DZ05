# Журнал тестовых циклов 19.10.2026

Каждый цикл завершается очисткой ДЗ05 в finally. Полные локальные журналы
находятся в .local/cycle-console*.log; для сдачи публикуются обезличенные результаты.

1. Первый apply: привязка floating IP опередила подключение подсети к роутеру.
   ExternalGatewayForFloatingIPNotFound; добавлен depends_on для association.
   Все 22 созданных ресурса удалены, managed state пуст.
2. Повторный apply создал 23 ресурса. Nova console подтвердила загрузку ОС,
   cloud-init и SSH. Внешний TCP/22 недоступен с рабочего места.
   Все ресурсы цикла удалены, managed state пуст.
3. Временная ошибка read-only API при получении списка подсетей.
   Платные ресурсы не создавались; finally подтвердил отсутствие ресурсов
   по собственному префиксу и пустой state. Добавлены ограниченные повторы чтения.
4. Внешний SSH TCP/443 также оказался недоступен с единственным разрешённым /32.
   Проверены ACTIVE сети/роутера/портов, SNAT, назначенная security group и FIP.
   Все ресурсы удалены; API-аудит подтвердил нулевые остатки ДЗ05.
5. Сравнение с ДЗ06 выявило второй адрес оператора для прямого маршрута.
   В локальные tfvars ДЗ05 добавлен дополнительный подтверждённый /32;
   публичные SSH-диапазоны не расширялись до /0. Двух адресов оказалось недостаточно;
   после таймаута все ресурсы удалены.
6. Переиспользована подписанная HTTP-проба прямого маршрута из ДЗ06, с собственным
   ключом и службой. Подтверждён дополнительный адрес, добавлен только его /32;
   SSH заработал. cloud-init вернул 2 при status=done: установку остановили
   предупреждения образа. Все ресурсы удалены.
7. Проверка result.json подтвердила отсутствие fatal errors. sudo выдавал
   предупреждение о неразрешимом hostname, мешавшее чтению JSON.
   В cloud-init включён manage_etc_hosts. Все ресурсы цикла удалены.
8. MySQL 8.0.46 установлен на трёх узлах. В Ubuntu-пакете Router нет стандартной
   mysqlrouter.service; удалена попытка остановить отсутствующую службу,
   системный пользователь для собственной otus-router создаётся явно.
   Все ресурсы цикла удалены.
9. Подготовка всех ВМ прошла. Стандартный mysqld.cnf перезаписывал bind-address
   из dz05.cnf значением localhost. Конфигурация переименована в zz-dz05.cnf,
   добавлена проверка фактического @@bind_address и TCP/3306 до AdminAPI.
   Все ресурсы цикла удалены.
10. Кластер создан. Bootstrap Router не смог определить hostname приложения;
    добавлен явный report-host приватного адреса. Для mysqlsh отключён wizard,
    WRITESET задан заранее. Все ресурсы удалены.
11. Полный успех: импорт, пять тестов Django на MySQL, admin/media через SSH,
    отказ PRIMARY, затем SECONDARY и восстановление. Удалены 25 ресурсов;
    state и API-инвентарь ДЗ05 пусты.
12. Повторное независимое развёртывание собственными Python/Terraform:
    проверки пройдены, дополнительно сверены все поля импортированных статей
    и сохранность подтверждённых записей между отказами. Все 25 ресурсов удалены,
    отсутствие подтверждено API. См. results.md.

JSON cycle-*.json содержит фактические success/cleanup_success и время каждой
завершённой попытки. Неудачные циклы не являются доказательством работающего MySQL.
