API и SSH, затем проверку записи. Это время подтверждения сценария,
а не точное время переключения MySQL. Нулевой простой не заявляется.
Первый успешный цикл подтвердил запись после отказов через 13,88/16,34 с.

переинициализация кластера в этих сценариях не применялись.

Исторических дампов, фикстур и media-архива ДЗ04 не найдено, включая
