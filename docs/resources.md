# Состав ресурсов и квоты

| Роль | Число | vCPU/ГиБ на узел | SSD на узел |
|---|---:|---:|---:|
| MySQL InnoDB Cluster | 3 | 2/4 | 20 ГБ |
| Nginx, Django, uWSGI, MySQL Router | 1 | 1/2 | 20 ГБ |

Итого 7 vCPU, 14 ГиБ RAM, 80 ГБ basicssd, один floating IPv4,
одна приватная сеть /24, один обычный роутер, четыре порта ВМ и одна
группа anti-affinity БД.
Весь стенд в ru-9a: проверяется отказ ВМ, не отказ ЦОД.

Удаление выполняется отдельной командой после проверки. Остановка ВМ не удаляет диски и IP.

Перед созданием deploy получает актуальные квоты и потребление через Nova,
Neutron и Cinder. [Сохранённый preflight](preflight.json) относится к выполненным
испытаниям; для нового запуска требуется свежая проверка.

Помимо ДЗ05 сценарий консервативно резервирует ёмкость для независимого ДЗ06:
всего 8 ВМ, 15 vCPU, 28 ГиБ RAM, 160 ГБ SSD, два floating IP,
по две сети, подсети и роутера. Текущее потребление других стендов также
вычитается из свободной квоты. Ресурсы других ДЗ не изменяются.
