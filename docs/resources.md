# Состав ресурсов

| Роль | Число | vCPU/ГиБ на узел | SSD на узел |
|---|---:|---:|---:|
| MySQL InnoDB Cluster | 3 | 2/4 | 20 ГБ |
| Nginx, Django, uWSGI, MySQL Router | 1 | 1/2 | 20 ГБ |

Итого 7 vCPU, 14 ГиБ RAM, 80 ГБ basicssd, один floating IPv4,
одна приватная сеть /24, один обычный роутер, четыре порта ВМ и одна
группа anti-affinity БД.
Все узлы размещаются в одном выбранном сегменте пула. Проверяется отказ ВМ;
граница отказоустойчивости не включает отказ целого ЦОД.

Перед созданием ресурсов deploy автоматически проверяет квоты и текущее
потребление проекта Selectel, учитывая резерв для независимого стенда ДЗ06.
При недостаточной доступной ёмкости создание ресурсов не начинается.

Удаление выполняется отдельной командой после проверки. Остановка ВМ не удаляет диски и IP.
