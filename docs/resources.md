# Состав ресурсов

| Роль | Число | vCPU/ГиБ на узел | SSD на узел |
|---|---:|---:|---:|
| MySQL InnoDB Cluster | 3 | 2/4 | 20 ГБ |
| Nginx, Django, uWSGI, MySQL Router | 1 | 1/2 | 20 ГБ |

Итого 7 vCPU, 14 ГиБ RAM, 80 ГБ basicssd, один floating IPv4,
одна приватная сеть /24, один обычный роутер, четыре порта ВМ и одна
группа anti-affinity БД.
Весь стенд в ru-9a: проверяется отказ ВМ, не отказ ЦОД.

Удаление выполняется отдельной командой после проверки. Остановка ВМ не удаляет диски и IP.
